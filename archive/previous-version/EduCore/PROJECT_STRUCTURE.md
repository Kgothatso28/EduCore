# Project Structure

Projects created:

- EduCore.Api - ASP.NET Core Web API host and controllers
- EduCore.Application - Application contracts and abstractions
- EduCore.Domain - Domain entities and value objects
- EduCore.Infrastructure - EF Core DbContext and persistence
- EduCore.Shared - Shared cross-cutting components
- EduCore.Web - Blazor web shell (placeholder)
- EduCore.App - .NET MAUI app (placeholder)
- EduCore.Tests - Unit tests
